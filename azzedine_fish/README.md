# Azzedine Fish

برنامج مكتبي عربي لإدارة محل الأسماك مبني بـ Python وCustomTkinter وSQLite.

## المزايا

- تسجيل الدخول والمستخدمون وصلاحيتا «مدير» و«موظف».
- إدخال البضاعة يدوياً داخل الفاتورة من دون حفظ المنتجات مسبقاً.
- قائمة اختيار سريعة لأسماء الأسماك، ويمكن تعديلها من الإعدادات أو كتابة اسم جديد مباشرة.
- الزبائن والموردون والمصاريف.
- عند اختيار الزبون تظهر جميع فواتيره وإجمالي مشترياته مع الفتح والطباعة.
- فاتورة متعددة المنتجات مع الخصم والضريبة وطرق الدفع.
- حساب الربح اعتماداً على سعر الشراء وسعر البيع المكتوبين في كل فاتورة.
- فواتير PDF بمقاس A4 أو 80mm أو 58mm وQR Code.
- فاتورة احترافية بألوان المتجر وشعار افتراضي، مع زر لاختيار شعارك من الإعدادات.
- لوحة تحكم وتقارير يومية وأسبوعية وشهرية وسنوية.
- تصدير Excel وCSV وPDF (توفر الدالة العامة في `utils/exporter.py`).
- نسخة احتياطية واستعادة آمنة مع فحص سلامة SQLite.
- تخزين البيانات في `%LOCALAPPDATA%\AzzedineFish` على Windows.

## التثبيت والتشغيل

ثبّت Python 3.13 من الموقع الرسمي وفعّل خيار `Add Python to PATH`، ثم افتح موجه الأوامر داخل مجلد المشروع:

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

أو شغّل `run.bat` بعد تثبيت المتطلبات.

بيانات الدخول الأول:

- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

غيّر كلمة المرور وأنشئ مستخدمي المتجر قبل الاستخدام الحقيقي.

## إنشاء EXE

انقر مرتين على `build_exe.bat` أو نفّذ:

```bat
python -m PyInstaller --clean --noconfirm AzzedineFish.spec
```

ستجد الملف في `dist\AzzedineFish.exe`.

## هيكل المشروع

```text
azzedine_fish/
├── main.py                 نقطة التشغيل
├── app.py                  النافذة والتنقل
├── config.py               المسارات والألوان
├── database/               الاتصال والمخطط
├── models/                 المستودعات وCRUD
├── services/               المصادقة والفواتير والتقارير
├── views/                  صفحات الواجهة وعناصرها
└── utils/                  PDF والتصدير والنسخ الاحتياطي والأمان
```

## ملاحظات الطباعة العربية

يستخدم البرنامج خط Tahoma أو Arial الموجود في Windows. للحصول على تشكيل واتجاه عربي أدق داخل PDF يمكن تثبيت الحزمتين الاختياريتين:

```bat
pip install arabic-reshaper python-bidi
```
